# BulAdmin CRM / BulAdmin ERP

Вътрешна система на БУЛАДМИН на https://cloud.buladmin.eu/: клиенти, сделки и задачи (CRM), артикули, оферти, фактури и плащания (ERP). Изградена е като [портала](https://github.com/buladmineood/portal) и използва същото Microsoft приложение.

| Част | Къде | Технология |
|---|---|---|
| Страници | корен на репото (`*.html`, `assets/`) | статичен HTML/JS на GitHub Pages |
| API и вход | `worker/` | Cloudflare Worker на `cloud.buladmin.eu/api/*` |
| Данни | SharePoint сайт `/sites/cloud` | Microsoft Lists през Microsoft Graph |

Вход: Microsoft, Google или имейл и парола. Достъпът е само с покана от администратор.

## Раздели

- **CRM:** контрагенти (клиенти, потенциални клиенти, доставчици, партньори), лица за контакт, сделки по етапи (табло и списък), задачи със срокове.
- **ERP:** артикули и услуги с цена, ДДС и наличност; оферти, проформи, фактури и кредитни известия; плащания.
- **Администрация:** потребители с роли (Администратор, Потребител, Наблюдател), данни на фирмата за документите.

Всяка промяна се записва в история: кой, кога и кои полета.

## Правила за документите

- Черновата няма номер. Номерът се дава при издаване и след това документът не се променя, а само се анулира.
- Фактурите и кредитните известия са с обща поредица от 10 цифри. Офертите и проформите: `OF-2026-0001`, `PF-2026-0001`.
- ДДС се смята върху данъчната основа за всяка ставка (20%, 9%, 0%). При 0% се изисква основание.
- Валутата е EUR.
- Издадена фактура за стока намалява наличността, а кредитно известие я връща.
- Оферта може да стане проформа или фактура, а фактура може да получи кредитно известие.
- Плащанията се отбелязват по издадена фактура или проформа; статусът става „Частично платен“ или „Платен“.

```
npm run dev   # локален преглед с демо данни, http://localhost:8790
```
